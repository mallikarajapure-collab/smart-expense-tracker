## 💸 Overview

**Smart Expense Tracker** is a menu-driven Python console project for recording everyday expenses and viewing simple spending totals and category-wise entries.

## ✨ Features

- Add an expense with a name, category, and amount.
- View the total of recorded expenses.
- Review expenses by category.
- Navigate through a simple text menu.

## 🧰 Technology

- Python
- Lists and tuples
- Loops, conditions, and user input

## ▶️ Run Locally

The repository's Python file is named `expenses = [].py`.

```bash
python "expenses = [].py"
```

## 🔄 Typical Workflow

1. Launch the script.
2. Choose an option from the console menu.
3. Enter the requested expense details.
4. Review the total or category-wise view.
5. Exit the menu when finished.

## 📌 Scope & Limitations

This version is a basic learning project. The current repository file name and simple in-memory data approach mean you should not assume persistent storage, charts, bank integration, or automatic transaction imports are available.

## 🔮 Ideas for Later

- Save expenses to CSV or SQLite.
- Add monthly summaries and budget limits.
- Validate amounts and category names.
- Add a simple visual dashboard.
